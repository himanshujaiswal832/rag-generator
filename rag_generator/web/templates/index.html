Developer REST API

Integrate this generated RAG application programmatically.

cURL Query Example 
curl -X POST http://localhost:5000/api/apps/{app_id}/query \
  -H "Content-Type: application/json" \
  -d '{
    "question": "What is the liability cap under Section 11?",
    "top_k": 4,
    "hybrid_alpha": 0.5
  }'
Python SDK / Requests Example 
import requests

res = requests.post(
    "http://localhost:5000/api/apps/{app_id}/query",
    json={"question": "What is the primary endpoint?", "top_k": 4}
)
data = res.json()
print("Answer:", data["answer"])
print("Confidence:", data["confidence"])
for cit in data["citations"]:
    print(f"- {cit['source_name']} (p.{cit['page_number']}): {cit['snippet']}")
